# Studio dependencies

The studio serves these pinned dependencies and fonts locally. The original concepts retain their existing credits and dependencies.

- GSAP 3.15.0 (core, CSSPlugin, ScrollTrigger, Observer): https://gsap.com/ — standard no-charge license, included in `vendor/gsap/LICENSE.txt`.
- Lenis 1.3.27: https://github.com/darkroomengineering/lenis — MIT, included in `vendor/LENIS-LICENSE.txt`.
- Mona Sans variable 5.3.0 package from Fontsource: https://github.com/github/mona-sans — SIL Open Font License 1.1, included beside the font. Weight and width axes; Latin subset.
- JetBrains Mono 400 5.3.0 package from Fontsource: https://github.com/JetBrains/JetBrainsMono — SIL Open Font License 1.1, included beside the font. Latin subset.

Weather: Open-Meteo, https://open-meteo.com/, current conditions at São Paulo, cached for 15 minutes. The public interface links its attribution when a reading is displayed. Time uses the browser’s Intl implementation with `America/Sao_Paulo`.
