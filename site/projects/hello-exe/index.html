01 / The brief

The imagined subject

A fictional designer-engineer's portfolio presented as a working desktop of interactive mini applications.

The visitor

People exploring the interface and creative-development work of fictional designer Juno Rebelo.

The design question

How can a portfolio prove interface craft by behaving like software?

02 / From looking to doing

Play it here.

What to try

    Procedural chrome lettering and a 3D cursor introduce the desktop.

  2. 02

    Open, drag, focus, minimize, restore, and close app windows; a dock and mobile Focus window action keep them reachable.

  3. 03

    Use a ticket kiosk, FM synthesizer, variable tile-font tester, pixel forecast, virtualized table, typing readme, and recycle bin.

    Theme/sound controls, copy-email feedback, and consistent visibility pauses support the desktop.

03 / Decisions that shape the experience

Decision / 01

Make the desktop usable

Windows can open, drag, focus, minimize, restore and close. A dock keeps apps reachable, with a Focus window action for the smaller mobile workspace.

Desktop capture

Decision / 02

Put the proof inside the apps

The kiosk, synthesizer, tile-font tester, forecast, table, readme and recycle bin each have their own working behavior. Theme, sound and visibility controls make them parts of one system.

Phone capture
