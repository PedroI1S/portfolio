( Rules )

One ink.*cobalt, since issue 01 Six ()*per issue, give or take a mug things.*two issues a year No restocks.*when it's gone, it's sorted

Each issue starts as a list on the studio wall. Things we'd buy, things we'd keep, things a client once gave us that we still use. We cross most of it out. What's left gets made once, in one ink, by the same three workshops in Porto and Leicester.

Nothing is printed on spec. We order what the last issue sold, plus a few. When an issue sells out, we don't reprint it. We start the next list.
